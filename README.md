# Formulário com JavaScript 

Criando um formulário simples e funcional para cadastro de usuários, com validação utilizando HTML, CSS e JavaScript.
O objetivo é garantir que o usuário preencha os campos corretamente antes de enviar o formulário.

## 🚀 Funcionalidades  
✅ **Validação de todos os campos**  
✅ **Erros exibidos diretamente abaixo de cada input**  
✅ **Somente envia o cadastro quando todos os campos estão válidos**  
✅ **Verificação instantânea ao perder o foco do input**
